# DramaFinder 2.2.0

DramaFinder 2.2.0 keeps checkboxes, radio buttons, switches and `vaadin-select`
working on Vaadin 25.4, and rounds out the API for components without an
element class: a `GenericElement` can be focused and checked for its enabled
state, and a typed query can search any tag.

## Upgrading from 2.1.0

No source changes are needed. Two behaviours differ:

- **Checking a checkbox, radio button or switch clicks its label** (#294).
  `check()` / `uncheck()` (and every element built on `HasCheckedElement`)
  click the visible label, and Playwright reads the checked state from the
  control it labels. A control without a label is still clicked on its input.
- **`ElementQueries.find(page, tag)` accepts `.` in a tag name** (#295), as
  `VaadinElement.getLightDomChildren(..)` already did. Both now share one
  tag-name check.

## Vaadin 25.4 compatibility (#294)

- Vaadin 25.4 stretches the native input of `vaadin-checkbox`,
  `vaadin-radio-button` and the switch under the slotted label, which is
  painted on top, so `check()` / `uncheck()` timed out with "label intercepts
  pointer events". They now click the label.
- `vaadin-select` 25.4 dropped its `sr-label` slot and sets `aria-label` on the
  value button. `SelectElement.getAriaLabel()` and `assertAriaLabel(..)` read
  either, so they work on 25.3 and 25.4.

## New API

- **`GenericElement` focus and enabled state** (#296). It implements
  `FocusableElement` (`focus()` / `blur()` on the host) and
  `HasDisabledAttributeElement` (`isEnabled()`, `assertEnabled()`,
  `assertDisabled()`, read from the `disabled` attribute Flow sets on any
  component disabled with `setEnabled(false)`). `VaadinElement.of(..)`, the
  light-DOM lookups and `find(page, tag)` return elements that have them.
- **`find(page, VaadinElement.ANY_TAG)`** (#295), and the `Locator` overload,
  query every light-DOM element whatever its tag, for a lookup that only knows
  an id, a test id, a class, a theme or an attribute:

  ```java
  GenericElement billing = find(page, VaadinElement.ANY_TAG).withTestId("billing").single();
  ```

  The CSS filters extend the selector as they do for a tag, and
  `includingShadowDom()` works after it.
