# DramaFinder 2.2.4

DramaFinder 2.2.4 handles menu bar items collapsed into the overflow menu and
reads more of the Grid's accessibility: its own name, its column alignment and
the i18n names Vaadin 25.3 gives its sorters and selection checkboxes.

## Upgrading from 2.2.3

One behaviour differs:

- **`MenuBarElement.getItemLabels()` no longer lists "More options"** (#334).
  Once the overflow button was shown, it was returned as one of the menu bar's
  items. It is now left out; the items collapsed into it are still listed.

## New

- **Menu bar overflow** (#334). When the menu bar is too narrow, it collapses
  its trailing items into a "More options" menu.
  `MenuBarElement.getOverflowItemLabels()` lists them, and
  `MenuItemElement.isOverflowed()`, `assertOverflowed()` and
  `assertNotOverflowed()` check one item. A collapsed item is not clickable in
  place, for a user or a test: `click()` and `openSubMenu(..)` on it fail at
  once instead of waiting until the timeout. Open the menu with
  `openOverflowMenu()`, or look the items up through `unfoldingOverflow()` so
  that a collapsed item opens "More options" first and the same test runs at
  every viewport width.
  See [MenuBarElement](../specifications/MenuBarElement.md#items-in-the-overflow-menu).
- **`GridElement.getColumnTextAlign(columnIndex)` and
  `assertColumnTextAlign(columnIndex, align)`** (#143) read a column's
  `textAlign`, including the `left` and `right` values of Vaadin 25.3.
  See [GridElement](../specifications/GridElement.md#column-text-alignment).
- **Accessible names in the Grid** (#143).
  `HeaderCellElement.getAccessibleName()` and `assertAccessibleName(..)` read
  the header cell's name as the browser computes it (`i18n.sorter` on a
  sortable column, `i18n.selectAllUnavailable` when the select-all checkbox is
  hidden). `GridElement.getSelectAllCheckbox()` and
  `RowElement.getSelectionCheckbox()` return `CheckboxElement`s, named by
  `i18n.selectAll` and `i18n.selectRow`.
  See [GridElement](../specifications/GridElement.md#accessible-names-of-the-selection-column).

## Fixes

- **A Grid named with `setAriaLabel(..)` has an accessible name** (#333).
  Flow puts the name on the `<table>` inside the grid's shadow root, not on the
  `vaadin-grid` host, so `getAccessibleName()` returned `null` and
  `withAccessibleName(..)` found no grid. Both now read it there, as they do
  for `setAriaLabelledBy(..)`.
  See [GridElement](../specifications/GridElement.md#finding-the-component).
- **`GridElement.findHeaderCell(..)` finds the selection column's header**
  (#143). On a multi-select grid it returned no cell for that column.
- **The menu bar overflow is read once the layout has settled** (#334). In a
  container that animates its width (an app layout switching its drawer to
  overlay mode), the menu bar lays its items out again on each frame, so an
  overflow menu opened meanwhile lost its items. `openOverflowMenu()` and
  `getOverflowItemLabels()` now wait until the menu bar's size holds still.
- **`ConfirmDialogElement` reads only its own message.** Its message locator
  could also match elements in the component's shadow root. Lookups of a
  component's own children (dialog, confirm dialog, app layout, details,
  accordion panel, form layout, login, avatar group, menus) now use
  Playwright's `css:light` engine, which never enters a shadow root.
